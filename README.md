# Homebrew Tap for BarKeep

Official Homebrew tap for [BarKeep](https://github.com/Reno09r/BarKeep) — a lightweight macOS menu bar manager with floating HUD panel.

## Installation

```bash
brew install reno09r/barkeep/barkeep
```

Or tap first, then install:

```bash
brew tap reno09r/barkeep
brew install --cask barkeep
```

## Update

```bash
brew upgrade barkeep
```

## Uninstall

```bash
brew uninstall --zap barkeep
```
